Week 2 of the YuvaIntern Data Science with Python Analyst Internship extends the Sephora Customer Review Analysis from exploratory findings to a documented data strategy and initial analytical validation. The report compares six candidate sources: two Kaggle Sephora datasets, a Hugging Face mirror, Amazon Reviews 2023, Google Trends and the Reddit Data API. It distinguishes the primary dataset from sources that were evaluated but not downloaded, and it does not count the Hugging Face mirror as independent evidence. The Kaggle Sephora Products and Skincare Reviews dataset was selected because it includes review ratings, recommendation values, review text, reviewer attributes, brands and a linked product catalogue.

The five review files and product catalogue used for the analysis were inventoried and assessed across eight data-quality dimensions. The work documents data types, missing values, duplicate rows, reviewer identifiers, recommendation coverage, referential integrity and category coverage. Findings include that all supplied reviews concern skincare; recommendation values are absent for every review before 2017; 64 rows contain placeholder reviewer identifiers; and 224 rows are exact duplicates after excluding the row counter. A data dictionary, source comparison, compliance checklist and preprocessing plan accompany the report.

Statistical analysis describes the relationship between star rating and recommendation among 926,423 reviews with a recorded decision (chi-square = 741,794, 4 degrees of freedom; Cramér's V = 0.895). A Kruskal-Wallis comparison across 95 brands with at least 1,000 reviews found a small effect (H = 18,073; p < 0.001; epsilon-squared = 0.017). Results are interpreted as associations, and the report notes dependence among repeat reviewers and structural missingness in recommendation values.

The NLP component is a feasibility pilot on 99,867 reviews. Sentiment classes were derived from star ratings, so these are weak labels rather than human-verified judgements. In an author-grouped holdout, VADER reached macro-F1 0.452, TF-IDF with multinomial Naive Bayes 0.649, and TF-IDF with logistic regression 0.706; grouped cross-validation for logistic regression averaged 0.704. The pilot is not a production model and no human-labelled validation experiment was performed. The repository includes the Week 2 report, notebook, scripts, saved results, tables and figures. Raw CSV data are excluded; reproduce the analysis by obtaining the source files and installing the documented dependencies.
